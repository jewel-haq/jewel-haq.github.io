# Jewel Haque — Researcher Portfolio

Personal academic portfolio site for Jewel Haque (M.Sc.Eng. candidate, Petroleum &amp; Mineral
Resources Engineering, BUET), built to support outreach toward a Ph.D. in CCUS
(Carbon Capture, Utilization &amp; Storage).

Live site: https://jewelbuet.github.io/jewel-haq/

## Stack

Static site — plain HTML, CSS and vanilla JS. No build step, no dependencies.

```
index.html
assets/
  css/style.css
  js/main.js
Jewel_Haque_CV.pdf
```

## Local preview

Serve the folder with any static file server, e.g.:

```bash
python -m http.server 4173
```

then open http://localhost:4173.

## Deployment

Served via GitHub Pages from the `main` branch root.
